# 最后防线 · 打僵尸 HTML Demo

NEW-1：原生 HTML、CSS、JavaScript 和 Canvas 实现的俯视角生存小游戏，无第三方依赖、无需构建。

## 运行

直接用桌面浏览器打开 `index.html` 即可，包括 `file://`。也可在仓库目录运行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。

## 操作

- 点击「进入隔离区」开始。
- WASD 或方向键移动；鼠标瞄准；按住鼠标左键或空格连续射击。
- P 或顶部按钮暂停、继续；切换窗口或标签页自动暂停。
- 点击「重新开始」随时重开，失败后可再次挑战。

每波僵尸数量及移动速度递增，第 4 波开始需要两发命中。接触僵尸损失 20 点生命，之后短暂无敌。清空一波后休息 2 秒并恢复 15 点生命，最高 100 点。最高击杀数保存在当前浏览器；存储不可用时仍能游戏。场景箱子仅作装饰，无碰撞。

## 验证

需要 Node.js 18 或更新版本：

```sh
node --test tests/engine.test.cjs
node --check engine.js
node --check game.js
```

自动测试覆盖移动与边界、弹丸命中、装甲、接触伤害和无敌时间、失败冻结、波次与回血、暂停、重开和生成数量。

浏览器手动验收：

1. 打开页面并开始，确认键盘移动、鼠标瞄准、左键及空格射击正常。
2. 按 P 暂停与继续，再切换标签页，确认自动暂停且返回后不会自动射击。
3. 清空第一波，确认进入第 2 波并回血；被围攻后确认结算。
4. 重开并刷新页面，确认单局状态重置、最高纪录保留。
5. 调整窗口大小，确认画布及鼠标瞄准坐标仍对应。

目前以桌面键鼠为目标，尚无触屏虚拟摇杆或音效。

## 文件

- `index.html` / `style.css`：中文界面、状态栏与覆盖层。
- `engine.js`：独立游戏模拟，同时支持浏览器脚本与 Node 测试。
- `game.js`：输入、Canvas 绘制和浏览器存储。
- `tests/engine.test.cjs`：核心玩法回归测试。

## NEW-2：僵尸 Boss

累计游戏时间达到 5 分钟时，从场地边缘生成一只僵尸 Boss，每局仅出现一次。暂停和失败后不计时，重开重新计时。Boss 体型更大，拥有 40 点生命，接触造成 35 点伤害；出现时显示警报，存活期间显示独立血条。击败计入一次击杀，Boss 存活时不会结算当前波次。
